INTRODUCTION                                                     *codex-intro*

codex.nvim opens the Codex CLI in a managed vertical terminal. It follows the
interaction model and <leader>a* key layout of claudecode.nvim, while keeping
the implementation dependency-free and native to Neovim.

==============================================================================
SETUP                                                            *codex-setup*

    require("codex").setup()

The `codex` executable must be on PATH. Neovim 0.10 or newer is required.

COMMANDS                                                       *codex-commands*

                                                    *:Codex*
:Codex [prompt]       Open Codex, optionally send prompt.
:CodexOpen             Open the side panel.
:CodexStart             Start Codex CLI.
:CodexResume            Open Codex's session picker.
:CodexContinue          Continue the most recent session.
:CodexToggle           Toggle the side panel.
:CodexFocus            Focus the side panel.
:CodexClose            Hide the side panel but keep the process alive.
:CodexStop             Stop Codex and close the side panel.
:CodexStatus           Show process status.
:CodexHealth           Check CLI, current project directory, and session status.
:CodexDiagnostics      Send current-buffer diagnostics; use ! for all buffers.
:CodexQuickfix         Send the current quickfix list to Codex.
:CodexReview           Ask Codex to review workspace changes without editing.
:CodexAdd              Send the current file; an Ex range adds line context.
:CodexSend {prompt}    Send a prompt to Codex.
:CodexSendText {text}   Send text; with ! do not press Enter.
:CodexTreeAdd {file}    Insert a file reference from a tree without submitting it.
:CodexSelectModel      Select a configured model or enter one.
:CodexSelectBuffer     Choose a buffer and insert its contents into Codex.

:CodexDiffAccept, :CodexDiffDeny, :CodexDiffAcceptAll,
:CodexDiffDenyAll are compatibility commands. Codex CLI applies changes
through its own workflow and does not expose claudecode.nvim's IDE diff
protocol, so these commands report that no nvim-managed diff is available.

==============================================================================
KEYMAPS                                                        *codex-keymaps*

Default mappings (when `keymaps.enabled` is true):

<leader>ac              Toggle side panel.
<leader>af              Focus/toggle side panel.
<leader>ar              Open Codex's session picker.
<leader>aC              Continue the most recent session.
<leader>ae              Send current-buffer diagnostics to Codex.
<leader>aR              Review current workspace changes without editing.
<leader>ah              Check CLI, current project directory, and session state.
<leader>ab              Send current file or insert a visual selection reference.
<leader>as              Insert the selected file reference into the Codex prompt without submitting it.
<leader>aa / <leader>ad Accept / deny current diff compatibility action.
<leader>aA / <leader>aD Accept / deny all diff compatibility action.
<leader>am              Select model.
<leader>ap              Choose a buffer and insert its contents into Codex.
<leader>ax              Stop Codex.

CONFIGURATION                                                    *codex-config*

See README.md for the complete option list. The most important options are:

terminal_cmd            String or argv list, default: "codex".
cwd                     Working directory; nil uses the current git root.
git_repo_cwd            Resolve cwd from the current file, default: true.
split_side              "left" or "right", default: "right".
split_width_percentage  Side panel width fraction, default: 0.35.
auto_close              Close panel after CLI exit, default: true.
startup_delay_ms        Settle time after the editable input appears, default: 300.
                       Startup dialogs keep text queued until the input is ready.
selection.include_text  Include selected in-memory text: "never",
                        "if_modified" (default), or "always".
selection.max_chars     Maximum selected in-memory characters, default: 12000.
diagnostics.max_items   Maximum diagnostic/quickfix entries, default: 50.
diagnostics.max_chars   Maximum diagnostic/quickfix characters, default: 12000.
models                  Values shown by :CodexSelectModel.
keymaps                 Keymap names and enabled flag.

Codex terminals are isolated by working directory. With the default
selection.include_text="if_modified", a visual selection from a modified
buffer also includes its current in-memory text so Codex does not read stale
on-disk source.
